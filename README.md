# Bunny Munch V10.9.5 - Version Badge Fix

This is a standalone, offline-capable Bunny Munch game ready for GitHub Pages.

## Fix
The illustrated desktop header already includes a version capsule. This patch stops drawing a second capsule over it and displays only the version text in the original capsule.

The working mobile art, maze gameplay, carrot goals, and saved progress remain intact.
