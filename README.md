# Bunny Munch V10.9.6 — Comfy Controls

GitHub Pages ready. Upload `index.html` into your repository's root and replace the previous one.

- Mochi and the ghosts move about 12% more slowly in Cozy, Normal, and Challenge modes.
- Mobile directional buttons are substantially larger and have wider spacing.
- Removed the empty third row in the mobile D-pad.
- Preserves all five worlds, six-maze carrot quests, artwork, menus, scores, and saved progress.

No dependencies. Runs as a single HTML file on GitHub Pages or offline.
