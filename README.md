# Bunny Munch V10.9.7 — Kawaii Controls

GitHub Pages-ready, single-file Bunny Munch game.

## What’s new
- Original reference-matched glossy pink directional pad featuring Mochi, hearts, and a bow.
- All four on-screen buttons have real large transparent touch targets.
- Preserves V10.9.6 cozy motion, world art, Carrot Quest, achievements, and saved scores.
- No external assets needed; index.html includes all artwork for offline play.

## Deploy
Place **index.html** at the root of your GitHub Pages repository.
Your saved progress stays in the browser when updating the same URL.
