# Bunny Munch V10.8 — Dreamy Screens

Play Bunny Munch as a fully offline single-file browser game, or publish `index.html` to GitHub Pages.

## New in V10.8
- Rebuilt the welcome screen and theme selection scene to more closely follow the user-provided pastel illustration references while keeping buttons interactive.
- Added glowing gradients, layered cloud scenery, shiny buttons, scene stickers, bubble title typography, and more detailed theme selection cards.
- Added the new glossy strawberry art from the user's reference as the Strawberry Garden bonus collectible.
- Preserves the V10.7 Carrot Quest completion goals (35%, 50%, 65%, 80%, 90%, 100%), five worlds and six mazes per world, keyboard/touch controls, no shop/currency, and backwards-compatible saved progress.

## Publish
Upload `index.html` to the repository root and enable GitHub Pages. No external dependencies.
